# 任务库是怎么来的

数据源只有一个：B 站 UP **叫我棉被** 的《鸣潮开服以来全任务攻略合集》
<https://space.bilibili.com/570235512/lists/6498351>

合集里 24 个视频按版本排（1.0 到 3.8），每个视频的分 P（P1、P2……）就是一条条任务。
所以 **任务名 = 分 P 标题**，扒下来之后只做两件事：剥掉标题里的宝箱/成就/声匣之类的水分，按 `【】` 标记判类型。

## 类型怎么定的

UP 在每个分 P 标题开头用 `【潮汐任务】`、`【纪闻任务】` 这样的方括号标了类型，直接照抄：

| UP 标的 | 这里用的 |
| --- | --- |
| 潮汐任务 / 潮汐续闻 | `main` 潮汐 |
| 伴星任务 | `comp` 伴星 |
| 道引任务 / 奇谭任务 | `tale` 道引 |
| 纪闻任务 / 异闻任务 | `side` 纪闻 |
| 危行任务 | `expl` 危行 |
| 隐藏任务 | `hidden` 隐藏 |
| 活动任务 / 捕鱼活动任务 | `event` 活动 |

少数没标 `【】` 但标题里写着「第X章 第X幕」的（比如 2.6 那批），兜底判成潮汐。

## 地区怎么定的

**这一条是低置信的，得说清楚。** B 站合集是按版本组织的，不是按地图组织的——
UP 把 3.0 那批纪闻、危行全塞在一个视频里，光看标题分不出哪条在拉海洛、哪条在罗伊冰原。

所以地区判定只有两档：

1. **名字里带地名** → 高置信。比如「古今多少故事·云陵谷」直接归今州，`subArea` 也一起填上。
2. **按版本批次推** → 低置信。1.0 批归今州、2.0 批归黎那汐塔、3.5 批归梦州……这样。
   版本映射表在 `tools/parse_bili.py` 的 `VER_REGION`，一个版本对一张大地图。

下面的分区域报告就是按这两档分的。**标了「推测」的那批，地区可能不对**，你要是玩到某条任务发现它在别的地图上，告诉我改。
