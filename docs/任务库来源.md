# 任务库来源与置信度

`data/quests.json` 里的任务名全部来自**库街区官方 wiki** 的「任务合集」目录
（目录 id 1249，共 381 条），类型标签也用它自己的分类：
潮汐 / 伴星 / 道引 / 纪闻 / 危行 / 隐藏。日常和活动任务（共 80 条）不进表。

问题在于：**库街区没有给任务标「属于哪个地区」这个字段。**
任务正文页和大地图接口都要登录态（`code 220 访问令牌不能为空`），
Fandom、biligame、prydwen、game8、hakush 全都连不上。

所以地区是这么判的：

| 依据 | 置信度 | 说明 |
|---|---|---|
| 主线任务 | 高 | 对照 Fandom 中文站「潮汐任务」页的分章分幕，一章对一章 |
| 名字里带瑝珑子地图名 | 高 | 「古今多少故事·北落野」这类，地名就在标题里 |
| 伴星任务 | 高 | 角色专属，本来就不属于任何地区，单独列一区 |
| 版本批次 | **低** | 用任务入库时间推断版本，再用版本推主打地区 |

低置信那批的原理是：`2.6 版本 = 桑古伊斯狩原`、`3.3 版本 = 罗伊冰原` 这种对应关系
是从库街区「区域探索」各地图的攻略帖标题里反推出来的（帖子里写着「2.6 一条龙」）。
一个版本里如果有跨地区的支线，就会被一起塞进主打地区。

**合计 309 条，其中 240 条的地区是这么推的。** 下面按地区列出每条属于哪一档，
你看到明显不对的，直接告诉我，或者自己改 `data/quests.json` 里那条的 `regions[].id`。
