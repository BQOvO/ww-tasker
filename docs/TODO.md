# 鸣潮地区任务查漏补缺 · 待办

## 现在能用的

- 三态打勾（未开始 / 进行中 / 已完成），点圆圈就换一档
- 每条任务可以写一行备注
- **18 个区域 / 309 条真实任务**（数据来自库街区官方 wiki 的「任务合集」）
- 左列按版本折叠，一次只展开一章；右列按任务类型分页签
- 左列进度 x/y + 进度条，底部「全部」汇总
- 「只看未完成」筛选
- 折叠成 236×30 的细条
- 透明度 30%–100%（面板底变淡，字始终实色）
- 点击穿透（锁定）
- 全局快捷键，三个都能在设置里改
- 多个存档，能新建 / 改名 / 删除
- 任务库从仓库拉更新、程序自己查新版
- 自己的图标（exe 资源、窗口、任务栏都是它），7 帧 ico 从 16 到 256

## 已知限制

- **独占全屏看不见**。Windows 上任何悬浮窗都画不出来，只能让游戏跑无边框窗口 / 窗口化全屏
- 存档只记任务 id 不记名字，所以 id 不能改（改了等于那条进度丢了）
- 检查更新是同步 HTTP，网络卡的时候会顿一下（在后台线程，不冻 UI）
- 0.1.0 那版的占位任务（id 形如 `jz.main.01`）已经作废，升级时会被自动剔掉
