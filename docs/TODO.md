# 鸣潮地区任务查漏补缺 · 待办

## 现在能用的

- 三态打勾（未开始 / 进行中 / 已完成），点圆圈就换一档
- 每条任务可以写一行备注
- 8 个区域，左列进度 x/y + 进度条，底部「全部」汇总
- 「只看未完成」筛选
- 折叠成 236×30 的细条
- 透明度 30%–100%（面板底变淡，字始终实色）
- 点击穿透（锁定）
- 全局快捷键，三个都能在设置里改
- 多个存档，能新建 / 改名 / 删除
- 任务库从仓库拉更新、程序自己查新版
